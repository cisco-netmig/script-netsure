# Netsure

## Overview
**Netsure** is a tool designed to check and validate the state information and configuration of network devices. It utilizes **TextFSM** with **NTC-Templates** to parse command outputs and compare them against expected values.

## Features
- Supports multiple checklist categories.
- Uses TextFSM parsing with NTC-Templates for structured data extraction.
- Enables customized regex-based validation.
- Provides structured reports on validation results.
- Integrated GUI for intuitive selection and execution of validation checks.

## Usage
- Add the network devices you want to validate.
- Select the checks to be performed from predefined checklists.
- Run the validation process.
- View the generated reports for insights on compliance.
